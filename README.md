# ZapTivi Marketing Demo Playlists & EPG

Repository: `https://github.com/oaniworks-creator/zaptivi-demo`

This repository contains production-standard, legal, copyright-free IPTV demo assets for ZapTivi:
- **`demo_playlist_01.m3u`**: Showcase playlist with 2 4K channels.
- **`demo_playlist_02.m3u`**: Multi-category playlist with 8 varied channels across Nature, Sports, Cinema, Docs, Racing, Arts, and News.
- **`demo_epg.xml`**: Authentic 7-day XMLTV Electronic Program Guide with varied show durations and descriptions.
- **`logos/`**: 10 TV-grade PNG badge logos (180x144 px) matching each channel.
- **`generate_epg.py`**: Python script to dynamically re-generate the 7-day EPG at any time.
